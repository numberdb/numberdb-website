{% extends 'base.html' %} {% comment %} Django's default page says "Not Found. The requested resource was not found on this server." A draft answers exactly that to anybody who may not see it -- saying "you may not see this" would confirm a table of that name exists -- and a session that has ended turns the drafts somebody was reading into that page, all at once. Which reads as: the tables have been deleted. That happened, to a person who had made the drafts, and cost a few minutes of believing the server had lost them. The fix has to leave the answer as uninformative as it was, so the paragraph below is on *every* not-found page: for an address that never existed, for a table that was never made, and for a draft the reader may not see. It confirms nothing, because it says the same thing on all three. {% endcomment %} {% block head-title %}Not found{% endblock %} {% block content %}
