The one rule with a reason beyond taste: a field's help text stays out of the way until somebody is in that field. Django renders every password validator as a bulleted list, so a sign-up page opened for the first time led with four sentences about passwords before a single character had been typed -- rules read as a warning when nobody has done anything yet, and as help when they are in the field the rules are about. Scoped to the account forms, because elsewhere on the site a hint that only appears on focus is a hint nobody finds. {% endcomment %}
