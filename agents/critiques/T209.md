## What was checked hardest

* **Does the definition define?** It does: $U$ is the solution of
  Kummer's equation with $U(a,b,z)\sim z^{-a}$ as $z\to\infty$, which is
  DLMF's characterisation and pins the function down. Comment (8) then
  says which branch, and formula (1) gives the equation the definition
  only names. Two people would build the same table from it.
* **Parameters versus run.** The parameter lines say $a\in\mathbb Q$,
  $b\in\mathbb Q$, $z>0$, which is the family; the grid actually
  computed is in the complete-note, and the note is a clause that
  finishes the sentence "complete: no (…)". This is the split the skill
  asks for, done right.
* **The reader holding a number.** The numbers are the first thing on
  the page, headed $U(a,b,z)$ with the three parameters, and the title
  names the function. Rows run by $|a|$ then $|b|$, positive first, so
  $a=1/2$ and $a=-1/2$ are adjacent.
* **The two programs.** `z.hypergeometric_U(a, b)` exists on a Sage
  complex ball and the comment saying the method is called on the
  argument is the one thing a reader would otherwise get wrong.
  `mpmath.hyperu(1, 1, 1)` prints the stored row.

## Findings, ranked

### 1. "Elementary rows are not listed separately" does not say they are absent

Comment (9) opens: "Elementary rows are not listed separately." A
reader who looked up $U(1,2,z)=1/z$, found no row, and reads this
sentence cannot tell whether such rows are listed together with
something, listed elsewhere, or not listed at all. "Separately" implies
a place they are listed with something else, and there is none: the
nine elementary $(a,b)$ pairs on the grid are simply omitted, which is
what the complete-note's "every non-elementary entry" means. The
comment is also where "elementary" gets its meaning, and the reader
meets the word in the complete-note before reaching it.

Fix: "Rows whose value is an elementary function are omitted. When $a$
is a non-positive integer, $U(a,b,z)$ is a polynomial in $z$ by (3);
when $b=a+n+1$ with $n\in\mathbb{Z}_{\geq0}$, it is $z^{-a}$ times a
polynomial in $1/z$ by (4), and the case $n=0$ is $U(a,a+1,z)=z^{-a}$."
One sentence changes. Worth doing.

### 2. Two keywords name functions the table then says it is not

`Keywords` carries "parabolic cylinder function" and "Whittaker
function", at the same weight as the title. Somebody typing either lands
on this table first, and the page's only word on the subject is comment
(10): "This is Tricomi's function $U(a,b,z)$, not the parabolic cylinder
function $U(a,z)$ or the Whittaker function $W_{\kappa,\mu}(z)$." That
is a search hit whose page answers no. The keywords are defensible only
if the page tells that reader how to get from what they hold to a row
here, and the relations are one line each in DLMF, checked numerically
while reading:

* $W_{\kappa,\mu}(z)=e^{-z/2}z^{\mu+1/2}\,U(\tfrac12+\mu-\kappa,\,1+2\mu,\,z)$
  (DLMF 13.14.3);
* $U(a,z)=2^{-1/4-a/2}e^{-z^2/4}\,U(\tfrac a2+\tfrac14,\,\tfrac12,\,\tfrac{z^2}2)$
  for the parabolic cylinder function (DLMF 12.7.14).

Fix: add both to `Formulas`, and let comment (10) point at them: "The
parabolic cylinder function $U(a,z)$ and the Whittaker function
$W_{\kappa,\mu}(z)$ are different functions; they are expressed through
this one by (11) and (12)." Then the keywords earn their place. The
other way out is to drop the two keywords, which is smaller but serves
nobody. Worth doing, and the same remark applies to the Kummer $M$
draft beside this one, whose keywords carry "Coulomb wave function"
and whose comment says it does not store the Whittaker function.

### 3. Formula (6) names erfc and does not link it, because it cannot yet

Formulas (5) and (7) link $E_1$ and $K_\nu$ to their tables; (6)
leaves $\operatorname{erfc}$ plain. The corpus's table of the error
function is T197, a private draft, so there is nothing to link today and
`audit_table` is right to say nothing. When T197 is public, (6) should
read "where $\operatorname{erfc}$ is HREF{…}[the complementary error
function]" and `Similar tables` should gain the row, in the same words
as the $E_1$ one. Noted so the dependency is written down somewhere.

### 4. The sibling table is missing from Similar tables, because it has no number

Kummer's $M(a;b;z)$ is the other standard solution of the equation
this table's definition names, and it is prepared in the repository
(`generators/kummer-m-values-rational-parameters`) with `table = "TBD"`.
That is the one relation on this page worth more than the other three
together, and it is absent because the draft has not been created. When
it has, add "holds Kummer's function $M$, the other standard solution
of Kummer's equation" here and the reverse gloss there. Two notes on
that pairing while it is still cheap: the $M$ draft writes
$M(a;b;z)$ with semicolons and this table writes $U(a,b,z)$ with commas,
where DLMF uses commas for both; and its `comment-simple-rows` has the
same "not listed separately" sentence as finding 1.

### 5. The rigour note hedges where it need not

"against (7) wherever $b=2a$ and the corresponding Bessel value could be
computed" leaves a reader wondering which ones could not. On this grid
$b=2a$ at $(1/2,1)$ and $(3/2,3)$ only ($(1,2)$ is elementary and
omitted), twelve rows, and arb computes $K_0$ and $K_1$ at every
argument here. If all twelve were checked, say "on the twelve rows with
$b=2a$"; if some were not, say which. Also, the note nowhere says what
$(a)_s$ in formula (4) is; "where $(a)_s$ is the Pochhammer symbol"
after the formula costs six words. Small.

### 6. The Ramanujan gloss is the weakest relation on the page

"stores a Gauss hypergeometric family, before the confluence that gives
Kummer's equation" is true of any ${}_2F_1$ table, and T178's
$F_r(x)={}_2F_1(1/r,1-1/r;1;x)$ does not become $U$ under any
confluence. It is a fair sideways pointer for a reader browsing
hypergeometric functions, so leave it, but a shorter gloss claims less:
"a Gauss hypergeometric family; Kummer's equation is its confluent
limit". Noted only.

### 7. Fifteen pairs of rows hold the same number

Fourteen are Kummer-transformation partners at $z=1$, where the factor
$z^{1-b}$ in formula (2) is 1: $(1/2,0,1)$ and $(3/2,2,1)$, and so on.
The fifteenth is $U(1,1/2,1/2)=U(3,5/2,1/2)$, which is not from (2): it
follows from $U(a+2,b+2,z)=U''(a,b,z)/(a(a+1))$ and Kummer's equation
at $z=b$, which give $U(a+2,b+2,b)=U(a,b,b)/((a+1)b)$, and $(a+1)b=1$
at $a=1$, $b=1/2$. Search by number deduplicates exact repeats, so a
reader is answered once either way, and both rows are genuine values of
the family. Nothing to change; written down so the next person who
counts distinct values is not surprised.

## What is right and should stay

work exactly as the skill asks. Comment (8) says which branch and why
the values are real, in two sentences. The generator's docstring opens
with the three commands and explains the one non-obvious call. The
rigour note names the guard the generator uses and the radius bound the
generator's own comment records as measured. None of that should be touched while fixing 1 and 2.
