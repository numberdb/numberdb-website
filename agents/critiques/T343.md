## The audit

    parameter unit takes 2 names (bits, nats), each carrying entries of its
    own, so this reads as 2 tables sharing one title and one value column.

**Right in form, wrong here, and the table already answers it.** Nats and bits
are one number in two conventions, invertible by a constant in both
directions, which the skill names as one of the three good answers; the
audit's own escape clause is "say so in the definition", and the definition
says it in those words ("as one number in two conventions, the logarithmic
units `nats` and `bits`"). The structural tell is clean too: the value column
is headed `$D(P\|Q)$`, not the word `value`, because one symbol is true of
every row. And this is the corpus's settled shape for the subject, not an
invention — T241, T339 and T340 all carry a `unit` parameter taking exactly
`nats` and `bits`, and all three are published. Nothing to do.

The audit said nothing about the other parameter that fits the same tell,
`distribution`, which takes seven names and which both other parameters repeat
under. The silence is not a verdict, and the verdict is that it is also fine,
for the other reason the skill gives: `distribution` names *what the number is
of* — one divergence for each of seven named families — which is the blessed
shape, the same one T339 uses with ten names.

I agree with the audit on its one finding and found nothing it should have
flagged and did not. What follows is all reading, not arithmetic.

## Findings, ranked

### 1. The definition renames the object instead of defining it — worth doing

The page opens:

> For probability measures $P\ll Q$, the Kullback-Leibler divergence [1] is
> the relative entropy $D(P\|Q)$.

That is one name given for another, plus a symbol introduced without a
referent. A reader who does not already know what relative entropy is learns
nothing, and two people could not build the same table from it. The actual
definition is on the page, as Formulas (1) —
$D(P\|Q)=\int\log(\mathrm{d}P/\mathrm{d}Q)\,\mathrm{d}P$ — but it sits below
the definition, in a section whose job is identities.

Its own model table does this correctly: T339's definition reads "the Shannon
entropy CITE{WikiShannonEntropy} **is $H(X)=-\sum_x p(x)\log p(x)$**". T343
dropped the formula on the way across.

`$P\ll Q$` is the same problem one clause earlier: it is the one piece of
notation in the definition, it is unglossed, and to a reader outside measure
theory it reads as "much less than".

**Smallest fix.** Move Formulas (1) into the definition and gloss the symbol:
"For probability measures $P$ and $Q$ with $P$ absolutely continuous with
respect to $Q$, the Kullback-Leibler divergence, or relative entropy, is
$D(P\|Q)=\int\log(\mathrm{d}P/\mathrm{d}Q)\,\mathrm{d}P$."

### 2. The rule for reading a shape does not describe the shapes — worth doing

The `shape` parameter's constraint renders in the parameter list as

> the text before the semicolon gives the parameters of $P$, and the text
> after it gives the parameters of $Q$; within each side the parameters are in
> the order named by the distribution label and are separated by commas

Two of the seven families do not obey it.

**Binomial and negative binomial.** The label is
$D(\operatorname{Binom}(n,p)\|\operatorname{Binom}(n,q))$ and the key is
`2,1/2;1/3`. Under the stated rule, "the parameters of $Q$, in the order the
label names them" is $(n,q)$, so the text after the semicolon should be
`2,1/3`. It is `1/3`. The shared $n$ is written once, on the left, and nothing
says so. A reader applying the rule as written to `2,1/2;1/3` gets
$\operatorname{Binom}(2,1/2)$ against $\operatorname{Binom}(1/3,\cdot)$ and
stops. That is 432 of the 676 rows.

**Normal.** The label is $D(N(\mu_1,\sigma_1^2)\|N(\mu_2,\sigma_2^2))$, which
names variance, and the key is `0,1;0,2`. Under the stated rule `0,2` is
$\mu=0$, $\sigma^2=2$. It is not: the stored value for that row is
0.3181471805599453…, which is $\log 2 + \tfrac18 - \tfrac12$, so $\sigma_2=2$
and the key holds the *scale*. Comment (11) does say "the normal row uses
location $\mu$ and scale $\sigma$", so the document contains both answers, in
two places, and the one attached to the parameter is the wrong one.

The exponential label shows the table already knows how to fix this: it reads
"$D(\operatorname{Exp}(\theta_1)\|\operatorname{Exp}(\theta_2))$, with scale
parameters". The normal label is the one where the ambiguity actually bites
and it is the one with no gloss.

**Smallest fix.** Two clauses. In the `shape` constraint, add "a parameter
shared by $P$ and $Q$, such as $n$ or $r$, is written once, before the
semicolon". On the normal label, add ", with location and scale" as the
exponential label already does.

(The T339 critique found the same class of fault — a label that does not let
a reader read its own shape tuple — in the negative binomial and Zipf rows.
It has come across with the pattern.)

### 3. `Links` carries the request that asked for the table — worth doing

Reference [3] on the page reads "Requested in numberdb-data#56", pointing at
the GitHub issue. The skill is flat about this: a "table wanted" issue is
answered in the issue, and "the table carries no trace of the request: it is
encyclopedic, and who asked for it is not a fact about the mathematics". The
exception is an issue containing a derivation or a convention a reader needs,
cited for that content — this one is cited from nowhere at all. `CITE{WikiKL}`
and `CITE{SciPyStats}` appear in the prose; `CITE{Request56}` does not, which
also makes it the bibliography-as-furniture the skill warns about. T339, built
from the same kind of request, carries no such link.

**Smallest fix.** Delete the `Request56` entry.

### 4. Comment (13) describes a normal grid the table does not have — worth doing

> Rows with $P=Q$ are omitted because $D(P\|Q)=0$. Normal rows with
> $\sigma_1=\sigma_2$ are also omitted because
> $D(N(\mu_1,\sigma^2)\|N(\mu_2,\sigma^2))=(\mu_1-\mu_2)^2/(2\sigma^2)$ is an
> exact rational number for the parameters considered here.

Every normal row in the table has $\mu=0$ on both sides — all twelve keys are
`0,…;0,…`, and the completeness note says the grid is $N(0,\sigma_1^2)$
against $N(0,\sigma_2^2)$. So a normal row with $\sigma_1=\sigma_2$ is a row
with $P=Q$, covered by the first sentence, and the formula in the second
sentence is $0$ on every pair the grid can produce, not a nonzero rational.

What a reader takes from it is that the normal grid ranges over different
means and that those rows were dropped for being rational — and then they look
for a row with $\mu_1\neq\mu_2$, find none, and cannot tell whether such rows
were computed and dropped or never considered.

The sentence looks like a mis-adaptation of T339's, which is careful and
correct: "Rows whose **bit** value is an exact rational number are omitted;
each is named in the comment on the same distribution's nats row." Rational
*bits* is the case that arises; rational *nats* is not.

**Smallest fix.** Delete the second sentence. If the intent was to record a
decision about means, say it in the completeness note instead: that the normal
grid fixes both means at $0$, because a difference of means contributes the
exactly rational $(\mu_1-\mu_2)^2/(2\sigma^2)$ and nothing a reader needs a
hundred digits of.

### 5. The completeness note counts and never argues — worth doing

It runs to five lines of grid and does not contain the word "because". The
skill asks the opposite of the field: "Say which range you chose and why in
the completeness note. That sentence is the argument, and it is what a reader
checking whether their own number belongs here actually reads."

Two things in it a reader will stop on and the note does not address:

* **`11/100`.** The Bernoulli and geometric grids are
  $p,q\in\{1/2,1/3,1/4,1/5,1/10,11/100\}$ — five unit fractions and one
  two-decimal. Nothing says why that one is there. (In T339 it is not an
  oddity, because that table holds *every* two-decimal $p$ in a range; here it
  is a single survivor of that grid with no company.)
* **The narrower binomial set.** Bernoulli and geometric use six values of
  $p$; binomial and negative binomial use four, dropping $1/5$ and $11/100$. A
  reader who finds $D(\operatorname{Bernoulli}(1/5)\|\operatorname{Bernoulli}(1/2))$
  and then cannot find the $\operatorname{Binom}(3,\cdot)$ row above it has no
  way to learn whether that is a decision or an omission.

There is also "negative binomial pairs for $2\leq r\leq10$ and **the same
ordered distinct $p,q$**", which makes a reader count backwards through a
five-clause sentence to find which "same" is meant — the thing the skill's
"name it, do not point at it" rule is about.

**Smallest fix.** One clause of argument, and name the set rather than
pointing at it: "…; negative binomial pairs for $2\leq r\leq10$ and ordered
distinct $p,q\in\{1/2,1/3,1/4,1/10\}$, the probabilities common enough to be
met…" — and a sentence saying why `11/100` is in the Bernoulli grid (a
non-unit fraction, if that is the reason) or dropping it.

### 6. The third `Similar tables` relation is not a relation — worth doing

> Capacity of the $(d,k)$ run-length-limited constrained codes — belongs to
> the same information-theory family and uses the same nats and bits units for
> logarithmic quantities

The skill's whole point about `Similar tables` is that the relation is the
valuable part, the thing one table cannot hold. "Belongs to the same family"
restates that they are similar, and "uses the same units" is a fact about
formatting. Compare the first of the three on this same page, which is exactly
right and does work a reader could not do alone: "when $Q$ is uniform on $n$
points, $D(P\|Q)=\log n-H(P)$" — true, checkable, and it tells you what to do
with the other table.

Compare also T339's: "entropy per site in lattice models is a limiting entropy
rather than the entropy of one named distribution" — a relation that says how
the two subjects differ.

**Smallest fix.** Either name a relation — channel capacity is a maximised
mutual information, and mutual information is a Kullback-Leibler divergence
between the joint law and the product of its marginals, which is a real link —
or drop the row.

## Noted only, because I noticed

* **`complete: false` prints as "Table is complete: false".** The field is
  rendered verbatim into that sentence (`views.py:1128`), so the word written
  in the document is the word in the English on the page, and `false` is a YAML
  literal sitting in a sentence. The skill writes `no`, and so do 12 of the 15
  published tables I sampled — but T119 and T241 also say `false`, so this is
  a minority spelling rather than a unique slip, and nothing checks it. One
  word, if somebody is editing anyway.
* **"the first distribution".** In `rigour details`: "the normal and
  exponential rows with numerical expectations under **the first
  distribution**". The symbol is shorter than the phrase pointing at it and
  stays right when the sentence is edited: write "under $P$".
* **The `distribution` labels are divergences, not distributions.** The column
  headed `distribution` prints
  `$D(\operatorname{Bernoulli}(p)\|\operatorname{Bernoulli}(q))$ on $\{0,1\}$`
  on each of its sixty rows, under a value column already headed `$D(P\|Q)$`.
  It is informative — it is how a reader sees that both arguments come from
  one family — and I do not think it is worth changing; T339's labels are
  distributions ("Bernoulli$(p)$ on $\{0,1\}$") and are no shorter. The one
  part that is simply wrong is the tail: "on $\{0,1\}$" and ", with scale
  parameters" describe the *distributions*, and here they are hung off a
  divergence.
* **Named entry citations cannot reach a shape containing a comma.** Verified
  on the published T339, where the same key shape exists:
  `?entry=binomial,2,1/2,nats` resolves, and
  `?entry=distribution=binomial,shape=2,1/2,unit=nats` answers "This table has
  no entry…", because the resolver splits the named form on commas
  (`views.py:571`). For T343 that is 456 of 676 rows. This is a site
  limitation T343 *inherits* from the pattern it was built on rather than a
  fault of its own — the positional form, which is the form the skill
  documents, works on every row — so I would not change the keys for it. It is
  written up as a lesson proposal instead.
* **The Shannon relation names a case this table does not hold.** "when $Q$ is
  uniform on $n$ points" — no row of T343 has a uniform $Q$. The identity is
  still the right thing to say, since it explains what relates the two
  subjects; a reader hoping to combine one row of each will just not find the
  pair.

## Verdict

A good table, and visibly a careful one: built to a published sibling's
pattern, verified against SciPy on every entry, 100 significant digits
throughout, ordered so that $D(P\|Q)$ and $D(Q\|P)$ sit together, and clean
through the audit on the one question the audit knows how to ask.

The six findings above are all prose. Two of them — the definition that
renames instead of defining, and the shape rule that does not describe the
shapes — are worth an editor's attention before this is offered, because they
are the two a reader arriving with a number has to get past. The rest are
cheap. Nothing here needs a recomputation and nothing here needs the table
split.
