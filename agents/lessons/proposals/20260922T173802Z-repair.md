## `sage.arith.misc` does not export `catalan_number`
What happened: while checking T414's Catalan-series expansion under Sage, importing `catalan_number` from `sage.arith.misc` failed with `ImportError`, though `is_prime` imported from the same module. The check did not need a Sage-specific Catalan function; `math.comb(2*m, m) // (m + 1)` gave exact integers and let the all-entry p-adic comparison run.

What the skill says now: it names several functions that named Sage imports do not bring, but not the Catalan-number helper.

What it should say: if a generator or check needs Catalan numbers, do not assume `sage.arith.misc` exports `catalan_number`; use an explicit available import after testing it, or use the binomial formula with exact integers.

Evidence: `agents/sage.sh /tmp/t414_check.py` for T414 on 2026-09-22 first failed with `ImportError: cannot import name 'catalan_number' from 'sage.arith.misc'`; replacing it with `math.comb(2*m, m) // (m + 1)` made the check pass for all 566 entries.
