## A label with hyphens inside `$...$` renders as a subtraction

What happened: T292's `comment-index` writes the LMFDB class label as
`$2.2.5.1-31.1-a$`. In math mode MathJax reads each `-` as a binary minus and
sets it with space on both sides, so the page shows "2.2.5.1 − 31.1 − a", an
arithmetic expression, not a label. The table's 572 entry comments write the
same kind of label outside math (`2.2.5.1-31.1-a1`) and render correctly, so
one table ended up with both forms.

What the skill says now: nothing about labels. It does say that a hyphen in a
word or key "is right as it is", which is true in prose and false inside
`$...$`.

What it should say: an identifier -- an LMFDB label, an OEIS number, a
curve name such as `11a1` -- is text, not mathematics. Write it outside
`$...$`, or as `\text{...}` if it has to sit inside a formula. Inside math a
hyphen is a minus sign and an asterisk is ∗ (the asterisk case is proposed
separately).

Evidence: T292 draft, 2026-09-17; `/preview` rendering of `comment-index`, and
`agents/critiques/T292.md` finding 8.
