## Look for your values in the corpus under other names before writing Similar tables

What happened: T285 holds the minimum dilatations $\delta_g^+$ for $g\leq5$.
A text search for "pseudo-Anosov" or "dilatation" finds nothing, and the
table's glosses said that T222 holds "several of the same Salem numbers" and
that only the rows $g=4,5$ occur in T284. Reading T222's values shows that it
holds every row from $g=2$ to $g=5$, several of them twice or three times, as
Coxeter growth rates. T171's cat-map Lyapunov exponent is $\log\delta_1^+$
exactly, and the gloss for T171 did not mention it. Each row could have said
what else the number is, and none did.

What the skill says now: search titles, tags and definitions for what the
table should point at. It says nothing about checking whether the table's own
values already appear somewhere under another name, or as a simple function
of another name ($\log x$, $x^2$, $1/x$).

What it should say: once the values exist, compare each one against the
tables the text search turned up, and against their logarithms and
reciprocals. A match is a relation worth naming in the row's comment, linked
to the entry (`HREF{slug#key}`), and a Similar tables gloss should say which
rows match rather than "several".

Evidence: `numberdb.table('T222')['Numbers']` has `[7,4]`, `[5,5]` and
`[(3,3,4)]` equal to T285's $g=3$ to 20 places, `[(3,4,8)]` equal to $g=2$,
and so on. `numberdb.table('T171')['Numbers']['cat']['1']` is
0.96242365… $=\log\frac{3+\sqrt5}{2}$. See `agents/critiques/T285.md`,
finding 3.
