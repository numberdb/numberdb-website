# One lesson file per run

A run that hits something the skill should have warned it about writes it
here, as `<run stamp>-<stage>.md`, in the format `PROPOSALS.md` uses: what
happened, what the skill says now, what it should say, and the evidence.

One file per run, because two campaigns appending to one file conflict on
every merge, and a path no other run writes to cannot. `PROPOSALS.md` keeps
the 211 written before this and is still read alongside these.

Nothing here changes the skill. A person does that, after reading them --
which is the whole reason the format asks for evidence.
