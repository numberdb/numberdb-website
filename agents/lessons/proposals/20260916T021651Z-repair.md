## Cross-table links in `Definition` fail the audit even when they are first mentions

What happened: while repairing T255, the critique proposed linking
`sporadic finite simple group` in the `Definition` to
`HREF{Orders_of_sporadic_finite_simple_groups}`. That matches the skill's
plain reading of "first mention, once per section", and the API accepted the
edit. The next audit returned one finding:
`Definition links to another table; a cross-reference belongs in Similar tables or a comment`.
Removing only that definition link made the audit clean again.

What the skill says now: "Link the first mention of a thing to what explains
it" and "Link a table the first time it is named, and only the first time."
It does not say that `Definition` is an exception.

What it should say: do not put `HREF{...}` cross-table links in `Definition`.
Use `Similar tables`, `Comments`, or `Formulas` for cross-references to other
NumberDB tables, even when the linked object is first named in the definition.

Evidence: T255 repair on 2026-09-16. Revision
`1c341b564b1efcce6cd1116182b88cfb51c35f84d5d7e636b8f96fd03b61fe92` had the
definition link and `/api/table/T255/audit` returned the finding above;
revision `e42e81bb1bb5be5c251ce9cf87e4eb2e2af53cf0f013d56c92135581d4317b8a`
removed the definition link and audited clean.
