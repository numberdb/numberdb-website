# Proposed by the T401 critique, 2026-09-22

## `Similar tables` is a list of records, and any other shape is stored and shown to nobody

What happened: T401 (Coiflet scaling filters) writes its `Similar tables`
section as a mapping from slug to relation, which reads naturally and is
accepted by the write API without a murmur:

    "Similar tables": {
      "Daubechies_extremal-phase_scaling_filters": "the extremal-phase
          Daubechies scaling filters, using the same normalisation and
          reconstruction-filter orientation"
    }

The rendered page is 517,753 bytes and does not contain the string "Similar
tables". `numberdb_app/views.py` accepts three shapes -- a bare string, a list
of names, and a list of `{table, relation}` records -- and a mapping matches
none of them, so the branch that builds the section never runs. Nothing
refuses the document, nothing warns, and `audit_table` passes it clean: the
audit does read the mapping's values as prose, so it scans the sentences while
never asking whether they reach a page.

This is not a private mistake. T395, the Symlet table, is published with the
same shape, and its live page has no `Similar tables` either. Of the 102
tables T300-T401, 94 write the list-of-records shape and exactly those two
write a mapping.

What the skill says now: the section table says `Similar tables` holds "tables
*in this database* it relates to, with the relation named", and the paragraph
below it says the section "states the *relation*, in words". Neither says what
the value looks like, and a contributor writing a document by hand has no
reason to guess a list of two-key records over the mapping that says the same
thing more briefly.

What it should say: give the shape, once, where the section is described.

    Similar tables:
    - table: HREF{Other_table}[Other table]
      relation: stores the same constant in the other normalisation

A mapping from slug to relation is silently dropped by the renderer, and so is
anything else that is not a string, a list of names, or a list of these
records. If the relation is worth writing, check it is on the page before
offering the table: fetch the page and look for the heading.

Evidence: 2026-09-22, T401 critique. `GET /api/table?id=T401` for the
document; the page rebuilt whole by the sqlite draft-render recipe (records
918, status 200, 517,753 bytes) with `body.count('Similar tables') == 0` and
section order Numbers, Definition, Parameters, Formulas, Comments, Programs,
References, Links, Data properties. `curl https://numberdb.org/T395` (249,317
bytes, published) likewise contains no "Similar tables". `GET
/api/table/T401/audit` is `{"findings": [], "clean": true}`.
`numberdb_app/views.py:1031-1059` is the branch.
