# Proposed by the T285 growth critique, 2026-09-20

## A range justified by "the source stops here" has to be checked against the source's own remarks

What happened: T285 holds the minimum dilatations $\delta_g^+$ of pseudo-Anosov
maps with orientable foliations. Its completeness note read

    it holds $1\leq g\leq5$; in [1], the next cases $g=6,7,8$ are given only
    as lower bounds

which is a true sentence about the theorem it cites, and it stopped the table
two rows short. Four lines below that theorem, the same paper says:

    In addition, Aaber & Dunfield and Kin & Takasawa have found a pseudo-Anosov
    homeomorphism realizing $\delta_7^+$, and Hironaka has done the same for
    $\delta_8^+$. Hence, all the lower bounds in [that table] except for genus 6
    are known to be realized.

So $\delta_7^+$ and $\delta_8^+$ are known exactly, from two papers the cited
one names, and only genus 6 is open. The table has since been extended to
$g=1..5,7,8$ and is now the whole of what is known.

This is a general shape, not a fact about dilatations. A paper that computes
the first few members of a family almost always records, in a remark or in a
revised version, who supplied the next ones — that is what the remark is for.
A range taken from the theorem alone is a range as of the day the theorem was
written, and the arXiv version of the same paper is usually several years
younger than the theorem.

What the skill says now: section 2, "Say which range you chose and why in the
completeness note. That sentence is the argument". Nothing about where the
range's evidence should come from.

What it should say: add a sentence to that paragraph — when a range is
justified by "the source computes no further", read the source's remarks and
its later versions before believing it, and follow the papers it names. The
sentence a completeness note should be able to make is "this is everything
known", which is a claim about the literature and not about one theorem.

Evidence: 2026-09-20, T285. Lanneau–Thiffeault arXiv:0905.1302v3, Theorem 1.3
and the Remark after it; Hironaka arXiv:0909.4517 Corollary 1.5
($\delta_8^+=\lambda_{(1,8)}$); Hironaka's survey arXiv:1403.2987,
"$\delta_g^+$ has been computed for $g = 2,3,4,5,7,8$ … The exact value for
$\delta_6^+$ is not known." The two values were recomputed here to 100 digits
and match the ones now stored.

## `p.is_irreducible()` on a univariate rational polynomial hits the `PolynomialSequence_generic` import cycle

What happened: a check script that did what the skill's template does —
`import numberdb.sage as numberdb`, then name the rings it wants — called
`is_irreducible()` on an element of `PolynomialRing(QQ, 'x')`:

    import numberdb.sage as numberdb
    from sage.rings.polynomial.polynomial_ring_constructor import PolynomialRing
    R = PolynomialRing(QQ, 'x'); x = R.gen()
    (x**12 - x**7 - x**6 - x**5 + 1).is_irreducible()

    ImportError: cannot import name PolynomialSequence_generic

`is_irreducible` calls `factor`, `factor` builds a `Factorization`, and
`Factorization.__init__` calls `Sequence`, which is the circular import already
proposed on 2026-09-20 in `20260920T010637Z-critique.md` for `EllipticCurve`.
The same one-line fix works: `import sage.libs.singular.function` before the
ring imports, after which `is_irreducible()` and `factor()` both return.

This is a second, independent instance of that proposal, from a script with no
elliptic curve and no multivariate polynomial in it — which is the argument for
wording the skill's item generally ("anything reached through Sage's
`Sequence`") rather than naming `EllipticCurve` alone.

Evidence: 2026-09-20, two runs of `agents/sage.sh` on the deployed image. Cold,
the traceback is `polynomial_rational_flint.pyx:1669` →
`polynomial_element.pyx:10067` → `polynomial_integer_dense_flint.pyx:1650` →
`structure/factorization.py:306` → `structure/sequence.py:296` →
`multi_polynomial_sequence.py:173` → `plural.pyx` → `libs/singular/function.pyx:95`.
With the extra import, the same script prints
`x^12 - x^7 - x^6 - x^5 + 1 = (x^2 - x + 1) * (x^10 + x^9 - x^7 - x^6 - x^5 - x^4 - x^3 + x + 1)`.
